# Sirhcm Tinymesa

## How do I install these formulae?

`brew install sirhcm/tinymesa/<formula>`

Or `brew tap sirhcm/tinymesa` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sirhcm/tinymesa"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
